# OSS — Open Stream Software

**Stream Freely. Create Without Limits.**

OSS is a free, open-source mobile streaming studio. The initial development target is Android, with a lightweight core and an extension system for optional capabilities.

## Project status

Early development. This repository is being initialized; it is not yet a working streaming application.

## Principles

- Free and open source; no ads or paid feature gates.
- Lightweight core; optional features are extensions.
- Local-first operation; no account required for basic use.
- Explicit user consent for extension installation and updates.
- Signed, permission-scoped extensions and safe recovery from extension failures.

## Planned first milestones

1. Establish the Android application foundation.
2. Prove screen capture and RTMP streaming on a physical device.
3. Add a basic studio preview and scene model.
4. Introduce the extension manifest, validation, and manager.
5. Add official extensions and device-level testing.
